# Roadmap do Projeto

Este roadmap apresenta a evolução planejada do laboratório para ampliar profundidade técnica, cobertura de cenários e maturidade de entrega.

## Fase 1 — Fundamentos Kubernetes

**Status: concluído**

- Namespaces
- DNS entre namespaces
- Requests e Limits
- QoS
- LimitRange
- ResourceQuota

## Fase 2 — Networking e exposição de aplicações

**Status: planejado**

- Services NodePort
- Ingress
- Ingress Controller
- Gateway API

## Fase 3 — Configuração e segurança

**Status: planejado**

- ConfigMaps
- Secrets
- ServiceAccounts
- RBAC
- NetworkPolicies

## Fase 4 — Deploy profissional

**Status: planejado**

- Helm
- Kustomize
- GitHub Actions
- CI/CD
- Deploy de aplicação real

## Fase 5 — Dados e Kubernetes

**Status: planejado**

- PostgreSQL em Kubernetes para laboratório
- Jobs
- CronJobs
- Pipelines de dados
- Observabilidade
